## 🎬 AxisClip

### Uma ferramenta para transformar vídeos longos em cortes automaticamente.

</div>

O **AxisClip** é um projeto de automação para processamento de vídeos.

A ideia é receber um vídeo, realizar sua transcrição, identificar automaticamente os momentos mais relevantes e gerar cortes.

### 🔥 Como funciona

```text
📹 Vídeo
   │
   ▼
🎙️ Transcrição
   │
   ▼
🧠 Inteligência Artificial
   │
   ▼
🎯 Identificação dos melhores momentos
   │
   ▼
✂️ Geração dos cortes
   │
   ▼
💬 Legendas
   │
   ▼
🎬 Vídeo final
```
